# Nokia Remote

Bluetooth-пульт для управления музыкой на компьютере с телефона Nokia. Проект создавался для Nokia C5 и Linux.

Приложение на Java ME отправляет команды компьютеру через Bluetooth RFCOMM: переключает треки, управляет воспроизведением и громкостью.

## Управление

| Кнопка телефона | Действие |
|---|---|
| 5 / центр джойстика | Воспроизведение / пауза |
| 4 / влево | Предыдущий трек |
| 6 / вправо | Следующий трек |
| 2 / вверх | Увеличить громкость |
| 8 / вниз | Уменьшить громкость |
| 0 | Включить / выключить звук |

На экране отображается результат отправки команды или ошибка подключения.

## Требования

- Телефон с Java ME: CLDC 1.1, MIDP 2.0 и поддержкой Bluetooth API.
- Компьютер с Bluetooth.
- Сервер на компьютере, который принимает команды и управляет медиаплеером.

## Файлы проекта

- `src/RemoteMidlet.java` — исходный код приложения.
- `NokiaRemote.jar` — готовое приложение для телефона.
- `manifest.mf` — описание приложения и разрешения.
- `lib/` — компилятор и библиотеки для сборки.

## Настройка

1. Выполните сопряжение телефона и компьютера по Bluetooth.
2. Укажите Bluetooth-адрес компьютера в константе `URL` файла `src/RemoteMidlet.java`:

   ```java
   private static final String URL =
       "btspp://AABBCCDDEEFF:3;authenticate=true;encrypt=true";
   ```

   Вместо `AABBCCDDEEFF` укажите адрес компьютера без двоеточий. Число `3` — канал RFCOMM; он должен совпадать с каналом сервера.

3. После изменения адреса пересоберите приложение.
4. Передайте `NokiaRemote.jar` на телефон и установите его.
5. Запустите сервер на компьютере, затем приложение на Nokia.
6. Разрешите приложению использовать Bluetooth.

**Готовый JAR настроен на компьютер автора.** Для подключения к другому компьютеру необходимо изменить адрес в исходном коде и пересобрать приложение.

## Протокол

Приложение отправляет текстовую команду в кодировке UTF-8 с переводом строки:

```text
PLAY
PREV
NEXT
VOL_UP
VOL_DOWN
MUTE
```

После успешной обработки сервер должен ответить `OK` с переводом строки. Для каждой команды приложение открывает отдельное Bluetooth-соединение.

## Ограничения

В этой папке находится клиент для телефона. Для работы пульта также нужен сервер на компьютере. Совместимость с другими моделями телефонов зависит от поддержки Java ME и Bluetooth API.
